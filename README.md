# jTetris
This is an old online Tetris clone I made a long time ago. It used to be hosted on PlanetSourceCode back in the day but as Planetsourcecode is gone now I decided to host it here instead.

Features include:

- Blocks fall down gradually (Smoother animation effect) 
- A New Game+ mode with a more advanced set of blocks
- The configuration of the blocks and their rotations are read in from an external xml file. 
- Support for swipe gestures on mobile devices

This project makes use of the following dependencies
- JQuery : https://jquery.com/download/
- Touch Swipe JQuery Plugin:  https://github.com/mattbryson/TouchSwipe-Jquery-Plugin
- xml2json: http://www.fyneworks.com/jquery/xml-to-json/

This is actually a JavaScript version of my even older VB.NET "iTetris" which was based on DirectDraw.
